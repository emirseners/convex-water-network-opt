Notlar:
(1g) vana açık olduğu zaman komşu düğümlerin potansiyellerini eşit varsayıyor. (1b)’deki sağ tarafa sahip olmasını sağlamak.
Denklem (1e) pump curveleri modelde katıyor (https://usepa.github.io/EPANET2.2/3_network_model.html). Ancak convex değil.
Pump efficiency, pump power kavramları nasıl kullanılmalı?
Tasseff’lerin çalışmasında flow ub, lb’ları sıkılaştırmak için bir yöntem mevcut.
Vana ve pompalar açık oldukları zaman akış alt sınırlarını 0 mı?
İşletme probleminde d^2 ancak tasarım probleminde d^v.
Şimdiki flow bound hesaplama yönteminde flow boundlar d’ye bağlı (tasseff’lerdeki gibi). Bunu nasıl düzenlemeliyiz ki tasarım probleminde problemle karşılaşmayalım maksimumunu almak mümkün, ancak ister miyiz.


Modelde yalnızca sabit hızlı su pompaları (head pumps) değerlendirilmektedir. Vana objeleri kullanılmamaktadır ve yalnızca check valvelar modele katılmaktadır. Vana eklenmek istendiği zaman borunun check_valve parametresinin True yapılması gerekmektedir.


Parametreler:


duration
hydraulic_timestep
pattern_timestep
hydraulic_pattern: global demand pattern (optional)
global_efficiency: global pump efficiency (optional)
global_price: global energy price (optional)
global_pattern: global energy price pattern (optional)


Required object parameters
Junction:
name
base_demand
demand_pattern (optional, if not global hydraulic pattern, if not constant over time)
elevation (head_lb)


Reservoir:
name
base_head
head_pattern_name (optinal, if not constant head over time) (head_lb = head_ub)


Tank:
name
diameter (only cylindrical tanks are considered)
elevation (head_lb = elevation)
min_level
init_level
max_level


Pipe:
name
start_node_name, end_node_name
length
diameter
roughness
friction: roughness ve diameter kullanılarak Colebrook-White ile hesaplanıyor


Candidate Pipe:
kurulum maliyeti verileri .inp dosyası ile sağlanamadığı için dictionary olarak dışarıdan tanımlanabilir:
key = ‘pipe name’_’diameter’: str
value: Pipe verileri + Kurulum maliyeti


Valve:
Epanette pipe olarak tanımlanarak check_valve parametresi True yapılmalıdır.


Pump:
name
start_node_name, end_node_name
fixed_cost
variable_cost (energy_price, if not global price, if not 0.0000003) * (energy_pattern, if not energy.global_pattern, if not constant price over time)
pump curve
fixed cost ve variable cost sonradan da modele eklenecek şekilde düzenlenebilir

Head UB hesaplama:
head_upper_bound of each node = max(max of tank_head_ub, max of reservoir_head, maximum of junction_head_lb) + max_pump_head_gain

Burada aslında maximum of junction_head_lb over all junctions değerinin mantıklı tanımlanmış parametreler için yukarıdaki denkleme eklenmesine gerek olmaması lazım, ancak infeasible olmasın diye model eklenebilir.

Flow UB, LB hesaplama:
hidrolik denklemi ile tüm pipe’lar ve valve’lar için komşu düğümler sayesinde hesaplanır 
start_h_max - end_h_min = hydraulic loss	(if valve, flow_lb = 0)
Burada suyun alabileceği maximum hızın da değerlendirilmesi gerekebilir

flow_lb = - flow_ub eşitliği kullanılmadı
pumplar için flow_lb = 0, peki flow_ub’ları nasıl hesaplamamız gerekir?
